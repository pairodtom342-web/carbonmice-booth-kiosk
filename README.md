# carbonMICE Booth Kiosk

เว็บเปิดค้างบนจอทัชในบูธ (Android + Chrome · หมุนแนวนอน/แนวตั้งได้)

- **หน้าเริ่ม** → กด "▶ เริ่ม + เต็มจอ" 1 ครั้งตอนตั้งบูธ (Android ต้องมีการแตะจอก่อนถึงจะเล่นวิดีโอมีเสียงได้)
- **วิดีโอวน** 3 คลิป (`videos/`) เก็บลงเครื่องหลังเปิดครั้งแรก → เน็ตหลุดก็ยังเล่นต่อ
- **แตะจอ → เมนู**: 🎡 เกมบูท (เปิดในกรอบ มีปุ่ม 🏠 กลับวิดีโอ) · 🌐 platform (เปิด**แท็บใหม่** เพราะ platform ห้ามเปิดในกรอบ — ปิดแท็บแล้วกลับมาจอบูธ)
- **ไม่มีใครแตะ 5 นาที** → เตือน 30 วิ แล้วกลับวิดีโอเอง
- ปุ่ม ⛶ มุมจอ = เต็มจอ / ออกจากเต็มจอ

แก้คลิป/ลิงก์/เวลา: `CONFIG` ด้านบนของ `<script>` ใน `index.html`
