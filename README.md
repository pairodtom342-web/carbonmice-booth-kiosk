# carbonMICE Booth Kiosk

เว็บเปิดค้างบนจอทัชในบูธ (Android + Chrome · หมุนแนวนอน/แนวตั้งได้)

- **หน้าเริ่ม** → กด "▶ เริ่ม + เต็มจอ" 1 ครั้งตอนตั้งบูธ (Android ต้องมีการแตะจอก่อนถึงจะเล่นวิดีโอมีเสียงได้)
- **วิดีโอวน** 3 คลิป (`videos/`) เก็บลงเครื่องหลังเปิดครั้งแรก → เน็ตหลุดก็ยังเล่นต่อ
- **แตะจอ → เมนู**: 🎡 เกมบูท (เปิดในกรอบ มีปุ่ม 🏠 กลับวิดีโอ) · 🌐 platform (เปิด**แท็บใหม่** เพราะ platform ห้ามเปิดในกรอบ — ปิดแท็บแล้วกลับมาจอบูธ)
- **ไม่มีใครแตะ 5 นาที** → เตือน 30 วิ แล้วกลับวิดีโอเอง
- ปุ่ม ⛶ มุมจอ = เต็มจอ / ออกจากเต็มจอ

แก้คลิป/ลิงก์/เวลา: `CONFIG` ด้านบนของ `<script>` ใน `index.html`
คลิปดาวน์โหลดจาก YouTube wZLQ6A69Jtw + Facebook 2 คลิป (ของ carbonMICE/PEA) ด้วย yt-dlp

## Dashboard + วิดีโอโฆษณา (`dashboard/`)

ลิงก์กลางใช้ได้ทุกงาน: `dashboard/?event=<event-id>` (เพิ่ม `&ads=0` = ไม่มีวิดีโอ) · เปิด `dashboard/` เฉยๆ = หน้าสร้างลิงก์ (วางลิงก์ dashboard ของงาน → คัดลอก)

- dashboard `carbonmice.pea.co.th/event/<id>/dashboard?preview=true` เต็มหน้าในกรอบ (หน้านี้ยอมให้เปิดในกรอบ)
- วน: dashboard อย่างเดียว 5 นาที → คลิปแนวนอน (clip1) → 5 นาที → คลิปแนวตั้ง (clip2) → …
- กรอบวิดีโอมุมขวาล่าง พอดีคลิป · ปิดเสียงเป็นค่าเริ่มต้น (ปุ่มลำโพง) · ⤢ ขยายเป็นกล่องกลางจอ (พื้นหลังดำโปร่ง) · ✕ ปิดรอบนี้
- ปุ่ม "ขยายหน้าจอ" ของเราวางทับปุ่มเดิม (fixed top 16px กึ่งกลาง) → เต็มจอทั้งหน้า วิดีโอยังอยู่
- ปุ่ม "วิดีโอโฆษณา: เปิด/ปิด" โผล่เมื่อขยับเมาส์/แตะมุมซ้ายล่าง · จำค่าในเครื่อง (ลิงก์ `ads=` มีสิทธิ์เหนือกว่า)
- ทดสอบเร็ว: เติม `&gap=5` = รอ 5 วินาทีแทน 5 นาที
